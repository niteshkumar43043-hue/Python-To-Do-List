# Python To-Do List Application

A command-line To-Do List application built using Python. It helps users manage daily tasks, track their progress, and store task information permanently using JSON.

## Features

- Add new tasks
- View all tasks
- Delete tasks
- Mark tasks as completed
- Mark completed tasks as pending
- Assign task priorities (High, Medium, Low)
- Search tasks
- Edit task names and priorities
- Track task creation and modification timestamps
- View task statistics
- Save and load tasks using JSON

## Technologies Used

- Python
- JSON
- Datetime Module

## How to Run

1. Install Python.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Open the project directory:

   ```bash
   cd Python-To-Do-List
   ```

4. Run the application:

   ```bash
   python main.py
   ```
